## Render atual e julgamento visual

Browser MCP não estava disponível entre tools, portanto fallback Playwright local. Servidor Vite programático sobre source ORIGINAL, configFile:false, cache `/tmp/cvg-audit-20260913/vite-cache`, root `/home/ricardo/cvg-connect-desk/apps/desk-web`; `VITE_API_URL=/api` definido só no processo. Todas as rotas `/api/**` interceptadas com fixtures sintéticas; WebSocket substituído no browser. Nenhum dado real nem operação externa. Auth simulado torna a captura prova de layout/estados, nunca prova de segurança/auth/integridade de mensagem.

Procedimento reproduzível: `/tmp/cvg-audit-20260913/serve-web.mjs`, `/tmp/cvg-audit-20260913/render-web.cjs`. Resultados `/tmp/cvg-audit-20260913/frontend-render/results.json`; capturas individuais nessa pasta. Capturas fullPage mantêm resolução nativa (altura pode crescer), DPR1; viewport altura 812 nas larguras 375/390, 900 nas demais. Esta amostra difere das alturas canônicas 844/1024/768 em alguns casos e não satisfaz matriz C09 inteira. Artefatos anteriores na mesma pasta foram sobrescritos pela rodada final bem-sucedida sobre original com interceptação API correta. O servidor não usa HMR React plugin; React JSX é transformado pelo Vite/esbuild, e ordem de imports/CSS é a do source.

Inspecionados visualmente: `inbox-1024.png`, `inbox-375.png`, `login-1440.png`, `notes-375.png`. Login tem hierarquia forte, paleta própria, marca integrada, contraste aparente e formulário legível; Inbox mobile mantém conversa e composer alcançáveis; Notes mobile mantém reflow. Há muito tratamento atmosférico, mas não justifica acusar genericidade automática. No Inbox 1024, drawer fechado deslocado horizontalmente amplia documento; no histórico real simulado data antiga aparece como Hoje. Não pontuo fidelidade de screenshot: N/A (sem referência alvo). Não emito score visual global de produto nem aprovação AAA por amostra parcial.

Veredito: implementação visual substancial; **AAA visual NOT_ELIGIBLE**, amostra parcial e problema High de reflow. As notas são julgamento de aderência implementada, separadas desse gate.
